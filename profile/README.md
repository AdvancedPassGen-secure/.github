## Overview

**Advanced PassGen** is a free, open-source password generator designed for maximum security and ease of use.  
It allows users to create strong, random passwords of any length, customize their composition, and export them safely — all without an internet connection.

Available for **Windows** and **Android**, it is ideal for protecting online accounts, Wi-Fi networks, and confidential data.  
Advanced PassGen does not collect or transmit user information — every password is generated locally.

---

## Key Features

- 🔐 Generate passwords from 4 to 256 characters.  
- 🧮 Full control over character sets (letters, digits, symbols).  
- 🧠 Password strength indicator and entropy meter.  
- 📋 Auto-copy generated password to clipboard.  
- 💾 Export to TXT, CSV, or encrypted formats.  
- 🔒 Works fully offline, no cloud or telemetry.  
- 🎨 Light and dark themes, multilingual interface.  
- 🧩 Portable version for Windows (no installation needed).
